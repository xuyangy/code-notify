Missing a notification that requires user approval/input is the most serious issue. 
Performance drop is a serious issue (especially in order to fix a "bug" that happens rarely or has no serious consequences).

Tests can take a long time. Use risk-based judgment about when to run them: prefer the smallest targeted tests that meaningfully validate a change, and skip slow or redundant suites when the change is low-risk or adequately covered by inspection. State which tests were run or skipped and why.
