Feature release that adds container-based agent support, per-event sound pools
and Antigravity approval detection, on top of a long run of tmux
running-indicator and badge fixes, since `v2026.07.5`.

## New agents: pi and omp

- `cn on pi` / `cn on omp` install a lifecycle extension into the agent state
  directory, so agents launched inside a Docker container can still notify the
  host. No image rebuild, new mount or changed run flags are required.
- The container-side extension spools one small tab-separated file per
  lifecycle event; a host-side relay running in the tmux pane the container
  renders into turns those into ordinary notifier invocations, so badges, the
  running indicator, click-to-focus, snooze, sounds and voice all work
  unchanged.
- `omp` is spoken as "oh-my-pi" rather than letter-by-letter.
- `session_stop` can correct a primary claim that another session stole, and
  stays silent when the turn was interrupted rather than completed.

## Per-event random sound pools

- Alerts play a random file from `<pool>/<event>/`, so repeated alerts of the
  same kind vary, with sensible fallbacks (permission → question, limit →
  error) and a final fallback to the single configured sound.
- New `cn sound pool <dir>|on|off|default` and `cn sound test <event>`;
  `cn sound set` mutes the pools so one file plays for everything.
- Hook-type spellings (`SubagentStop/`) are accepted as folder aliases.
- The whole implementation is mirrored in `install-windows.ps1`.

## Antigravity approval dialogs

- Approval dialogs raised by Antigravity are detected in the pane and notified
  like any other permission prompt.

## Tmux running indicator and badges

- Badge and running-state updates are serialized with a per-window transition
  lock, so racing events cannot clear or overwrite a live turn's marker.
- An interrupt-detection watch clears the running indicator silently when a
  turn is cancelled, including cancels that leave no text behind, and retires
  an abandoned input pause instead of leaving it armed.
- The watch no longer tears down live turns, and a rejected permission prompt
  is handled without a false teardown.
- The settle safety net no longer double-toasts a preserved stop, and a short
  preserve-settle window lets a badge-only reconcile finish cleanly.
- A stop that is only rate limited now badges the window instead of passing
  silently.
- Stale approval alerts can no longer land on a successor turn.
- Redundant tmux history scans were removed.

## Other fixes

- Current `ask_user` hook configurations are no longer misread as legacy.
- The TTS voice cache is scoped to the spoken phrase rather than the project.
- New "Over to you!" completion wording, with refreshed message pools.
